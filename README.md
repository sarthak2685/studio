# Magical Theatre

Premium multi-page Next.js site for Magical Theatre — projection mapping, son-et-lumière, museums and landmark shows.

## Stack

- Next.js App Router + TypeScript + Tailwind CSS v4
- GSAP + ScrollTrigger, Framer Motion, Lenis

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Editable typed modules in `src/content/`:

- `site.ts` — brand, nav, contact
- `projects.ts` — all case studies
- `awards.ts`, `team.ts`, `services.ts`

## Media

Drop showreel and project stills/videos into `public/media/`. UI uses cinematic placeholders until assets are wired.
